CURRENT DIRECTION
-----------------
Ma Golide is fully headless and follows Edge Factory's local-data approach:

- CSV + DuckDB is the system of record and direct read/research surface.
- localdata/ is restored/saved as runtime state.
- scripts/daily.py --auto-once is the single unattended orchestrator.
- Content-addressed pregame/freeze/result ledgers are immutable.
- SQL, the coverage CLI and research commands provide read access.
- WhatsApp is an optional deduplicated operational heartbeat.

There is no web server, external database, or read-model synchronization
service. Do not reintroduce them.

Google Sheets is NOT the target system of record. Do not add a Google service
account to make the default runtime work. Do not reintroduce satellite
registration, worksheet acquisition, or Apps Script deployment into the daily
path. Legacy Sheets adapters are for explicit historical migration or guarded
compatibility export only, with packages isolated in the legacy extra.

PRIMARY COMMANDS
----------------
Offline verification:

  python -m pytest tests -q

Hermetic orchestration preview (no canonical DB file or external writes):

  python scripts/daily.py --auto-once --offline-fixture \
    --warehouse /tmp/magolide-check/warehouse.duckdb \
    --localdata /tmp/magolide-check --notify

  ALLOW_MAGOLIDE_WRITES=true python scripts/daily.py --auto-once --write

Headless reads:

DOMAIN RULES THAT STILL APPLY
-----------------------------
- Join providers by exact canonical home + away + aware start, or known
  provider event identity with metadata validation. Quarantine ambiguity.
- Keep one provider's prediction bundle coherent; never splice providers.
- Never fabricate quarter/alternate/live/team-total bookmaker markets.
- Expected totals and margins are model outputs, not book lines.
- Preserve separate pre/post prediction and book slots.
- Frozen pre-tip evidence rejects changed overwrites and accepts identical
  replays, including after DuckDB reload.
- Official quarter + overtime scores must reconcile independently to each
  team's final before research use.
- Missing provider keys disable only that provider and remain visible in
  coverage. Fixture verification is not live verification.

RESEARCH / PICK GATE
--------------------
The current assay evaluates frozen pre-tip moneyline predictions against
reconciled official finals. Every edge remains research_only and certified:
false. Do not publish official picks until chronological walk-forward
validation, actual-price ROI, CLV, decay handling, deterministic pick IDs and
freeze/replay tests exist.

BANKER / ROBBER REFERENCE
-------------------------
The existing assayer domain classification remains:

BANKER  = lower_bound >= 0.60 AND win_rate >= 0.72
       OR lower_bound >= 0.55 AND win_rate >= 0.62
ROBBER  = n < 10 OR win_rate < 0.50
NEUTRAL = remaining positive but uncertain segments

Minimum absolute lift: 0.03. Wilson z: 1.645. Shrinkage prior: alpha=2,
beta=2. These labels are research classifications, not automatic betting
authorization.

EXTERNAL WRITE BOUNDARIES
-------------------------
Canonical writes: ALLOW_MAGOLIDE_WRITES=true plus --write.
Fixture persistence: ALLOW_FIXTURE_WRITES=true plus an isolated warehouse.
WhatsApp sends: credentials, ALLOW_NOTIFICATION_WRITES=true plus send option.
Legacy Sheets writes additionally require ALLOW_SHEET_WRITES=true and an
explicit legacy CLI flag.

Never place credentials in localdata/, Git, reports or logs. Fixture reports
can be previewed but cannot trigger external notification. No live external
write is implied by a passing offline suite.
